MULTI-DEVICE WORKSPACE
Sincronização entre dispositivos
A aplicação funciona offline e guarda os teus dados localmente em IndexedDB, com uma cópia de compatibilidade em localStorage. Para transferir dados entre dispositivos, utiliza a exportação e importação de backups JSON. A sincronização automática por conta/cloud fica reservada para uma versão futura.

Boas práticas
Exporta uma cópia depois de sessões importantes de desenvolvimento. Guarda-a em pelo menos dois locais diferentes. A exportação inclui receitas, cocktails e respetivos metadados.
